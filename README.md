# Rust Sandbox

This repository is dedicated to isolated proof of concepts, benchmarking, and exploring Rust environment.

## Key Areas of Focus
- **Memory management**: Exploring ownership, borrowing boundaries, and lifetime rules.
- **Type Systems:** Implementing traits, generics, and pattern matching.
- **Data Structures:** Building fundamental computer science implementations to understand Rust's pointer patterns.
<hr />

*Note: This repository is a low-overhead development sandbox. Commits are pushed directly to main to preserve a rapid learning loop.*
